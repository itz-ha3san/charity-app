# C.14 — زیرساخت توسعه‌های آینده

این نسخه مدیریت حامی و کمک نقدی/غیرنقدی، تخصیص کمک به خانواده، دفتر گردش انبار، فرم عمومی درخواست حمایت، Notification Outbox، مختصات داخلی خانواده و PWA را اضافه می‌کند.

## کنترل‌ها
- تخصیص کمک و خروج انبار داخل Transaction و با `FOR UPDATE` انجام می‌شود.
- مبلغ تخصیص نقدی از مبلغ کمک بیشتر نمی‌شود و موجودی انبار منفی نمی‌شود.
- عملیات اصلی Audit می‌شوند.
- API عمومی پیگیری فقط کد، وضعیت و زمان‌ها را برمی‌گرداند؛ اطلاعات شخصی و تصمیم داخلی افشا نمی‌شود.

## Outbox
رکوردهای `queued` شامل channel، recipient، template key و JSON payload هستند. Worker خارجی باید آن‌ها را Claim و پس از فراخوانی Provider به `sent` یا `failed` تبدیل کند. این نسخه ارسال زنده SMS/Email را ادعا نمی‌کند.

## PWA و Offline
Service Worker فقط پوسته عمومی و صفحه Offline را Cache می‌کند. مسیرهای `/api`، `/auth` و `/public` Cache نمی‌شوند. داده پرونده و Mutation حساس آفلاین صف یا ذخیره نمی‌شود.

## ادامه Roadmap
اتصال واقعی SMS/Email و حسابداری، 2FA، امضای دیجیتال، Offline Sync رمزگذاری‌شده، نقشه پیشرفته و تحلیل پیش‌بینی پس از Threat Model و کنترل حریم خصوصی انجام می‌شوند.
