# راهنمای مهاجرت داده

1. از پنل C.10 قالب Excel را دریافت کنید.
2. نوع ردیف را `liaison`، `supervisor`، `family` یا `member` تعیین کنید.
3. کدهای ارتباطی، کد ملی و شماره پرونده را دقیق وارد کنید.
4. فایل را Preview کنید و تمام خطاهای ردیفی را اصلاح کنید.
5. ابتدا روی دیتابیس آزمایشی اجرا کنید.
6. پس از اجرای نهایی، گزارش تطبیق و تعداد منبع/واردشده را کنترل کنید.
7. رمزهای موقت رابط‌ها فقط یک‌بار نمایش داده می‌شوند و باید امن تحویل شوند.
Batch قبلی و Audit برای ردیابی حفظ می‌شود؛ فایل اصلاح‌شده Preview جدید می‌سازد.
