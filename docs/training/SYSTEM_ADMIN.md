# راهنمای مدیر سیستم

## شروع روزانه
وضعیت `/health`، `/ready` و پنل «وضعیت Production» را کنترل کنید. خطای دیتابیس، فضای آزاد کمتر از ۲۰٪، افزایش 5xx یا نبود Backup تازه باید فوراً بررسی شود.

## کاربران و دسترسی
کاربر را با سمت واقعی ایجاد کنید. Reset رمز همه نشست‌ها را می‌بندد و کاربر در ورود بعدی مجبور به تغییر رمز است. کاربر جداشده را غیرفعال کنید؛ حساب را مشترک نکنید. تغییر نقش و سمت در Audit ثبت می‌شود.

## امنیت
لاگ دسترسی حساس، رویدادهای ورود و سیاست نگهداری را دوره‌ای مرور کنید. Secretها فقط در Password Manager سازمانی نگهداری شوند. فایل `.env.production` و کلید Backup نباید در Git، ایمیل یا پیام عمومی قرار گیرند.
