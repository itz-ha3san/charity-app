# بسته تحویل سامانه

مالک سامانه باید نسخه، SHA-256 فایل Release، دامنه، محل Backup، مسئول فنی، مسئول کسب‌وکار و کانال Escalation را ثبت کند. Secretها جدا از این سند و فقط از کانال امن تحویل شوند. قبل از امضا، تمام موارد پنل «چک‌لیست تحویل» تکمیل، آخرین `npm run verify` و `npm run security:audit` موفق، UAT امضا و Restore آزمایشی ثبت شود. تحویل شامل Source، Migrationها، فایل‌های استقرار، راهنماهای نقش، API/Database Reference و Runbook Production است.
