# Backup و Restore

Backup روزانه با `npm run db:backup:rotate` و کلید مستقل انجام می‌شود. حداقل یک نسخه خارج از سرور اصلی نگهداری و Hash/تازگی آن مانیتور شود. فایل‌های پیوست داخل PostgreSQL هستند و در Dump قرار می‌گیرند. Restore فقط روی محیط آزمایشی تمرین شود. پس از Restore، Ready، تعداد پرونده‌ها، آخرین پرداخت، کاربران و یک سند نمونه کنترل شوند. نتیجه تمرین ماهانه در چک‌لیست تحویل ثبت شود.
